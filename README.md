# AirTrackpad

Смартфон как трекпад Apple Magic Trackpad для Windows по Wi-Fi: все жесты MacBook,
музыкальный «остров» в стиле iPhone Dynamic Island и панель приложений с иконками
запущенных программ и программ, закреплённых на панели задач Windows.

## Состав

| Папка | Что внутри |
| :--- | :--- |
| [`WebTrackpad/`](WebTrackpad/) | Python-сервер (WebSocket) и веб-интерфейс, который открывается на телефоне. Инструкция — [`WebTrackpad/README.md`](WebTrackpad/README.md). |

## Быстрый старт

1. Установите Python 3.10+ и запустите `WebTrackpad/start.bat` (зависимости поставятся сами).
2. В консоли появится QR-код и ссылка вида `http://192.168.x.x:5050/`.
3. Откройте ссылку на телефоне в той же Wi-Fi-сети.

## Возможности интерфейса

- Полный набор жестов macOS: клики, скролл, pinch, поворот, свайпы 2–4 пальцами, Mission Control, Exposé и т.д.
- Музыкальный «остров»: капсула плавно превращается в плеер (обложка, трек, прогресс, управление),
  понимает любой плеер Windows через System Media Transport Controls. Короткие провалы медиа-сессии
  остров не прячут, а появление/исчезновение не сдвигает остальной интерфейс.
- Панель приложений: запущенные окна + всё, что закреплено на панели задач Windows; тап запускает
  приложение, если оно не открыто, и переключает/сворачивает окно, если открыто.
- Подгонка под Pixel 9: размеры интерфейса и отступ от выреза камеры в полноэкранном режиме.
- Анимации на iOS-кривых (spring): остров, шторки настроек, док, HUD, иконки, смена темы.

## Автосинхронизация

Любое изменение в этой папке автоматически коммитится и отправляется на GitHub в течение
нескольких секунд — скрипт `sync-github.ps1` работает в фоне и запускается при входе в Windows.
Не попадают в репозиторий: `__pycache__`, `qr.png`, логи и корневой лаунчер `Запустить Трекпад.bat`
(см. `.gitignore`).
