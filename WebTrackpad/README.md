# 🍏 AirTrackpad — Веб-трекпад со всеми жестами MacBook для ПК

Превращает любой смартфон в полноценный трекпад Apple Magic Trackpad для Windows через локальную сеть Wi-Fi.

---

## 🖐 Полный список поддерживаемых жестов Apple

| Жест Apple | Действие на трекпаде | Действие в Windows |
| :--- | :--- | :--- |
| **Щелчок нажатием** | Тап 1 пальцем | Левый клик мыши (ЛКМ) |
| **Вспомогательное нажатие** | Тап 2 пальцами | Правый клик мыши (ПКМ) |
| **Смарт-масштабирование** | Двойной тап 2 пальцами | Увеличение / сброс масштаба (`Ctrl + +` / `Ctrl + 0`) |
| **Прокрутка** | Движение 2 пальцами вверх/вниз | Плавный вертикальный скролл (натуральный) |
| **Масштабирование (Pinch)** | Сведение / разведение 2 пальцев | Плавный зум (`Ctrl + Колёсико`) |
| **Поворот** | Вращение 2 пальцев относительно друг друга | Поворот изображения (`Ctrl + R` / `Ctrl + Shift + R`) |
| **Переход между страницами** | Свайп 2 пальцами влево/вправо | Вперёд / Назад в браузере и проводнике (`Alt + Right` / `Alt + Left`) |
| **Центр уведомлений** | Свайп 2 пальцами от правого края экрана | Открытие центра уведомлений Windows (`Win + N`) |
| **Перетаскивание тремя пальцами** | Касание 3 пальцами и перемещение | Перетаскивание окон и файлов (Drag & Drop) |
| **Поиск и детекторы данных** | Тап 3 пальцами | Открытие поиска Windows (`Win + S`) |
| **Отображение рабочего стола** | Разведение 4 пальцев в стороны | Показать рабочий стол (`Win + D`) |
| **Приложения (Launchpad)** | Сведение 4 пальцев вместе | Открытие меню «Пуск» / программ (`Win`) |
| **Mission Control** | Свайп 4 пальцами вверх | Просмотр задач Windows (`Win + Tab`) |
| **Exposé** | Свайп 4 пальцами вниз | Переключение активных окон (`Alt + Tab`) |
| **Переход между рабочими столами** | Свайп 4 пальцами влево/вправо | Переключение между виртуальными столами (`Ctrl + Win + Left/Right`) |

## 🚀 Как запустить

1. Запустите файл `Запустить Трекпад.bat` (или `start.bat` внутри папки `WebTrackpad`).
2. В консоли появится **QR-код** и прямая ссылка (например, `http://192.168.1.16:5050/`).
3. Наведите камеру телефона (подключенного к тому же Wi-Fi) на QR-код и откройте страницу в Safari или Chrome.
4. В приложении есть кнопка **«?»** вверху справа — это встроенная шпаргалка по всем жестам!

## 🎨 Дизайн и эргономика
- **Минимализм Magic Trackpad:** чистая матовая стеклянная поверхность без лишних надписей.
- **Интерактивный Touch Glow:** визуальное свечение под пальцами при касании.
- **Всплывающий HUD:** при срабатывании многопальцевых жестов появляется аккуратная плашка с названием действия (как в macOS).
- **Тактильная отдача (Haptic Feedback):** вибрация при кликах, свайпах и жестах (Force Touch).
- **Мобильная клавиатура:** ввод текста на ПК прямо с клавиатуры телефона (включая голосовой ввод).
- **Панель приложений (как панель задач Windows):** слева — список запущенных на ПК программ с их настоящими иконками **и все приложения, закреплённые у вас на панели задач Windows** (то, что внизу рядом с кнопкой «Пуск»). Закреплённые приложения показываются чуть приглушённо; тап по такому значку запускает программу, тап по запущенной — разворачивает и переключает на её окно, повторный тап сворачивает. Если приложение уже запущено, его иконка не дублируется. Список закреплённых приложений сервер читает из системной папки ярлыков панели задач, поэтому он всегда совпадает с Windows.
- **Музыкальный «остров» (Dynamic Island):** сверху появляется чёрная капсула в стиле iPhone, пока на ПК что-то играет. Тап — капсула **плавно превращается в карточку плеера** (обложка, трек, артист, прогресс, кнопки «предыдущий / плей-пауза / следующий»), повторный тап или свайп вниз её сворачивает. Появление, исчезновение, смена трека и разворот анимированы пружинными кривыми iOS. Работает с любым плеером, который видит Windows (Яндекс Музыка, Spotify, браузеры, VLC), через System Media Transport Controls — плагины не нужны.
- **Остров не дёргает интерфейс:** под капсулу всегда зарезервирована полоса сверху, поэтому строка с кнопками настроек не прыгает вверх-вниз, когда музыка появляется или пропадает. Короткие паузы медиа-сессии (например, между треками) не прячут остров — он исчезает только если музыка действительно перестала играть.
- **Размеры под Pixel 9 (411×923 css px):** верхняя панель подогнана так, чтобы все кнопки помещались на экране; в горизонтальной ориентации панель приложений сдвигается от левого края, чтобы не оказаться под вырезом камеры, а в полноэкранном режиме вырез камеры (сверху в портрете, слева/справа в ландшафте) учитывается отдельно.
- **Белая тема** — Настройки → «Белая тема». Остров и карточка плеера остаются чёрными, как на iPhone, а трекпад и панель приложений становятся светлыми.
- **Плавность как в iOS:** все появления, закрытия, свайпы и нажатия используют один набор пружинных анимаций (spring-кривые), а не резкие переключения. Включая системную настройку «Уменьшить движение» (reduce motion).
- **Чёткие иконки:** сервер отдаёт настоящую иконку 256×256 из exe (а не растянутую 32×32) и кэширует её по URL на год, поэтому панель не «мылит» и не перезагружает картинки.

## 🛠 Если телефон не подключается

1. **Одна сеть.** Телефон и ПК должны быть в одной Wi-Fi-сети (гостевые сети и мобильный интернет не подходят).
2. **VPN — самая частая причина.** Если VPN включён на телефоне или на ПК, он может заворачивать локальный трафик в туннель:
   - на телефоне отключите VPN **или** включите «обход локальной сети» / split tunneling для этого Wi-Fi;
   - на ПК в VPN включите доступ к локальной сети (LAN) и отключите kill switch;
   - либо подключите телефон к той же VPN и откройте адрес VPN-адаптера (сервер теперь показывает его в списке адресов);
   - в приложении нажмите на плашку **«Нет связи с ПК»** — там будут все адреса сервера и подсказки.
   - **Tailscale** (уже установлен на ПК): если VPN постоянно мешает, включите Tailscale на ПК и телефоне и откройте адрес `100.x.x.x` из списка — трекпад будет работать из любой сети, даже с мобильным интернетом.
3. **Брандмауэр Windows.** Запустите один раз файл `Разрешить доступ в брандмауэре.bat` от имени администратора — он создаст правило для портов 5050–5060 для **всех** профилей сети. Это важно: при включении VPN Windows часто считает Wi-Fi «общедоступной» сетью и блокирует входящие подключения.
4. **Неверный IP.** Сервер определяет адаптеры через Win32 и выбирает реальный Wi-Fi/Ethernet, а не VPN/Tailscale. Все адреса печатаются в консоли и доступны в приложении (Настройки → Подключение).
5. **Порт занят.** Сервер автоматически попробует порты 5050, 5052–5060. QR-код всегда генерируется уже для фактического порта.
6. **Зависимости.** `start.bat` сам установит `websockets` и `qrcode[pil]` из `requirements.txt`, если их нет.
7. **Музыкального «острова» нет.** Он читает системные медиа-сессии Windows и нуждается в пакетах WinRT. Если их нет, трекпад работает как обычно, просто без плеера. Поставить:
   `python -m pip install winrt-Windows.Media.Control winrt-Windows.Storage.Streams winrt-Windows.Foundation winrt-runtime`

## 🎯 Точность курсора

Windows может добавлять собственное ускорение к движению мыши. Для максимально предсказуемого поведения трекпада отключите **«Улучшить точность указателя»**:
Параметры → Bluetooth и устройства → Мышь → Дополнительные параметры мыши → вкладка «Параметры указателя».
