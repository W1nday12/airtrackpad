# Duolingo Streak Guard

Страховка от потерянного стрика: каждый день в **23:50** (за 10 минут до конца дня)
скрипт проверяет, продлён ли стрик, и если нет — завершает одну короткую историю
в твоём курсе. Всё пишется в лог, при проблемах показывается уведомление Windows.

> ⚠️ **Риски.** Это автоматизация аккаунта: она нарушает правила Duolingo, и за
> систематическое использование аккаунт могут заблокировать. Скрипт старается быть
> минимальным (одна история в день, без накрутки XP), но гарантий нет. JWT-токен —
> это доступ к аккаунту: не публикуй `config.json` (он уже в `.gitignore`).
> Если что-то пошло не так — лучше сделать урок руками, чем гнать бота.

## Что нужно

1. Python 3.10+ (уже установлен).
2. Токен `jwt_token` из твоего аккаунта.

### Как взять токен

1. Открой [duolingo.com](https://www.duolingo.com) в Chrome и войди в аккаунт.
2. `F12` → вкладка **Console**.
3. Вставь и нажми Enter:
   ```js
   document.cookie.match(/(^| )jwt_token=([^;]+)/)[2]
   ```
4. Скопируй длинную строку (начинается с `eyJ...`) и вставь в `config.json`:

```json
{
  "jwt_token": "eyJ...",
  "user_id": "",
  "from_language": "",
  "learning_language": "",
  "story_slug": ""
}
```

Языки и id можно не заполнять — подтянутся сами. `story_slug` нужен, только если
хочешь закрепить конкретную историю.

## Установка / проверка

```powershell
cd D:\Download\project\duolingo

# безопасная проверка: показывает состояние стрика, ничего не меняет
python duo_guard.py --check

# установить ежедневную задачу на 23:50
powershell -NoProfile -ExecutionPolicy Bypass -File install_guard.ps1

# сразу прогнать "настоящий" режим (если стрик ещё не продлён — завершит историю)
python duo_guard.py --run

# выключить стража
powershell -NoProfile -ExecutionPolicy Bypass -File uninstall_guard.ps1
```

Коды выхода `duo_guard.py --run`:

| Код | Значение |
| :-- | :--- |
| 0 | стрик уже продлён или история успешно завершена |
| 1 | (`--check`) стрик ещё не продлён |
| 2 | нет токена в `config.json` |
| 3 | Duolingo недоступен / токен не принят |
| 4 | не нашлась история для курса |
| 6 | завершить историю не удалось — нужно сделать урок вручную |
| 7 | история завершилась, но стрик не подтвердился |

## Файлы

| Файл | Что внутри |
| :-- | :--- |
| `duo_guard.py` | основной скрипт (только стандартная библиотека Python) |
| `config.json` | токен и настройки (**не коммитится**, в `.gitignore`) |

| `logs/guard-ГГГГ-ММ-ДД.log` | журнал работы |

| `install_guard.ps1` / `uninstall_guard.ps1` | задача планировщика |

## Если токен перестал работать

Duolingo обновляет токен при новом входе в браузере; старый может истечь.
Признак: `--check` пишет HTTP 401/403 или уведомление «токен истёк». Возьми
новый токен тем же способом и замени в `config.json`.
